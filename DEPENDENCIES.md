# Dependencies

## Runtime and development

- Node.js 22 or newer
- TypeScript 5.8
- `vscode-languageclient` 9.x
- `@types/vscode` 1.97.x

## Repository boundaries

The StructMark core is included as source in this repository so the language server can be built and tested independently. The canonical core project is maintained in [`oMiki0826o/StructMark`](https://github.com/oMiki0826o/StructMark).
