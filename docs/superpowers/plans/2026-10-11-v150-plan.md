# StructMark v1.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** Produce a complete v1.5.0 source tree with safe CLI writes, workspace indexing, a readable AST Tree, tests and release docs.

**Architecture:** Keep core, CLI and Next.js site separate. Add one public workspace-index helper, one CLI file-safety helper and one site AST Tree module; all remain dependency-light.

**Tech Stack:** TypeScript (NodeNext), Node 22, Next.js 14/React 18, built-in node:test.

**Spec:** docs/superpowers/specs/2026-10-11-v150-design.md

## Global Constraints
No breaking language syntax. The AST document version remains 1.1. `format --write` must be atomic; explicit output never overwrites existing file. No external fonts or imagery. Keep docs bilingual. Don't claim unrun tests pass.

## Review Focus
1. `format --write` symlink/permissions and interrupted write.
2. Workspace reference paths with `../` and unknown IDs.
3. `AST Tree` on nodes with no source range (document) or huge inputs.
4. Mobile keyboard access and width overflow.
5. Package publishing includes runnable CLI and built core.
