# StructMark v1.2–v1.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task by task. Test first, verify RED then GREEN.

**Goal:** 交付完整 StructMark v1.3.0 原始碼 ZIP，包含 v1.2 的開發工具與 v1.3 的工作區及搜尋能力。

**Architecture:** 保留 TypeScript AST 核心及 Next.js 靜態網站；CLI 透過 dist public API，跨文件語義驗證採無 Node 相依的核心工具，文件索引建置期生成。

**Tech Stack:** TypeScript 5.8、Node.js 22、React 18、Next.js 14、Node test runner。

**Spec:** `docs/superpowers/specs/2026-10-11-v1.2-v1.3-design.md`

## Global Constraints
- 保留 `.sm` 與 v1.1.1 語法行為。
- 不增加後端服務或外部 UI 依賴。
- `format` 預設不覆寫檔案。
- 無法驗證的功能不能聲稱測試通過。

## Review Focus
- 路徑 `../` 不得跳出工作區根目錄。
- 空文件、未知格式及無效參數不得無聲失敗。
- 編輯器切換語言不可丟失文件。
- 動態輸出的 HTML 必須跳脫。
- 大型文件與惡意輸入不應造成無限制處理。
