# Contributing

1. Read `AGENTS.md` and the applicable `.governance/` gate.
2. Keep changes scoped to the VS Code project and preserve the core/LSP boundary.
3. Run `npm test`, `npm run build` in `packages/language-server`, and `npm run build` in `packages/vscode`.
4. Describe validation results truthfully in the commit and pull request.

The project is currently a development source repository. Do not describe an unverified VSIX or editor integration as released.
