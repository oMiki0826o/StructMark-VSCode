# Task Lifecycle

1. Establish acceptance criteria (`CORE-001`, `CORE-013`).
2. Inspect related source, settings and tests (`ENG-001`).
3. Define scope, risks and permissions (`CORE-005`, `DEC-003`).
4. Pass the [pre-edit gate](../gates/pre-edit.md) before changing files.
5. Execute checks according to [validation policy](../rules/validation.md) (`CORE-009`).
6. Assess regression risk and final diff (`VAL-008`).
7. Report results and constraints precisely (`VAL-010`).
