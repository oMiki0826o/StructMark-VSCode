# Release Workflow

1. Confirm scope and version (`REL-001`, `REL-002`).
2. Check dependencies, tests and documentation (`REL-003`, `VAL-010`).
3. Build and inspect artifacts (`REL-004`, `REL-005`).
4. Pass the [pre-release gate](../gates/pre-release.md).
5. Publish only with authorization (`REL-007`).
