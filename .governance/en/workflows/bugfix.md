# Bug Fix Workflow

1. Collect reproduction steps and diagnostics (`CORE-002`).
2. Follow call graphs and lifecycle (`ENG-001`).
3. Form a testable root-cause hypothesis (`CORE-004`).
4. Reassess failed patch chains (`CONV-002`, `CONV-003`).
5. Make the smallest coherent fix (`ENG-006`).
6. Add regression tests and check affected paths (`VAL-004`, `VAL-008`).
