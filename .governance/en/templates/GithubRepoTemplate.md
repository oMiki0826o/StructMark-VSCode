# GitHub Repository Publishing Entry

This document indexes publishing templates rather than redefining agent behavior. For factual, safety or authorization decisions, consult the [core](../rules/core.md), [decision](../rules/decision.md) and [documentation](../rules/documentation.md) policies.

| Output | Reference |
| --- | --- |
| README | [README Template](github/readme.md) |
| License | [License Template](github/license.md) |
| Ignore rules | [.gitignore Template](github/gitignore.md) |
| Discord announcement | [Discord Release](github/discord-release.md) |
| Repository description | [Repository Description](github/repo-description.md) |

Only generate the outputs requested or applicable to the project. Versions, artifacts, compatibility and technologies must be factual and verified. Distinguish the project release version from supported platform versions. If bilingual, keep essential facts equivalent in both sections. Use official license text without inventing legal provisions. Existing `.gitignore` rules must be preserved and all local `data/` excluded. Screenshots, comparisons and release URLs belong in public documents only if they actually exist.
