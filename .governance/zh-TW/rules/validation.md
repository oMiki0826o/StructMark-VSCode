# 驗證與證據

### VAL-001 — Level 0：閱讀檢查

靜態閱讀檔案、設定與 Diff；不等於執行測試。

### VAL-002 — Level 1：語法與編譯

執行 Parser、Compile 或語法檢查，僅宣稱相應層級通過。

### VAL-003 — Level 2：靜態分析

Lint、型別檢查及 Import 分析只有執行後才可列為通過。

### VAL-004 — Level 3：單元測試

對局部邏輯進行獨立測試；可行時替 Bug 加回歸案例。

### VAL-005 — Level 4：整合測試

驗證模組間設定、資料庫、註冊與協作行為。

### VAL-006 — Level 5：冒煙測試

驗證最小完整流程可啟動、基本運作且正常關閉。

### VAL-007 — Level 6：真實環境

外部平台、硬體或第三方 API 只有實測後才能宣稱完整驗證。

### VAL-008 — 回歸檢查

檢查受影響的舊功能、Public API、設定及啟停流程。

### VAL-009 — 不得為綠燈破壞測試

不要為求通過刪除合理測試、放寬斷言或忽略失敗。

### VAL-010 — 驗證報告精確

列出實際執行命令、結果、範圍及未驗證限制。
