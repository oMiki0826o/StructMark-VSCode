凡涉及 README、LICENSE、`.gitignore`、Discord 發布文案或 GitHub Repo Description，必須先遵守 `templates/GithubRepoTemplate.md`。`templates/github/` 的拆分模板、README、Docs 與 Workflow 只能補充或引用，不得降低或改寫本入口的確認清單、雙語結構、徽章、授權與輸出檢查要求。

### DOC-006 — 建立 README 必須引用 GitHub Repo Template

只要任務包含建立、重寫或大幅更新 README，開始產出前必須先讀取並依照 `templates/GithubRepoTemplate.md`。若只修改與任務無關的錯字或連結，不需要重新產生整份 README；但仍不得違反該模板的既有結構與檢查要求。
