# 新專案建立

### BOOT-001 — 最低專案內容

實際需要時提供 README、LICENSE、忽略規則、依賴資訊、原始檔與可用入口。

### BOOT-002 — 依賴可追蹤

依技術棧使用一種主要依賴來源；無依賴時明確說明。

### BOOT-003 — 資料隔離

`data/ai/` 放本地協作資料，`data/runtime/` 放執行資料；`data/` 整體忽略，公開結論另整理至 `docs/`。

### BOOT-004 — 按需建立目錄

沒有用途的 tests、services、adapters 等目錄不預先建立。

### BOOT-005 — 產生結果可使用

初始化結果須有有效的 Agent 規範入口、正確路徑與必要的忽略規則。
